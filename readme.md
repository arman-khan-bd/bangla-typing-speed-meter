## ✨ বৈশিষ্ট্যসমূহ (Features)

*   **সরকারি পরীক্ষার নিয়ম (Govt Exam Rules):** সরকারি চাকরিতে টাইপিং টেস্টের নিখুঁত রেপ্লিকা। ৫% ভুলের নিয়ম (5% error threshold) এবং তার জন্য স্পিড পেনাল্টি হিসাব করে সঠিক WPM নির্ণয়।
*   **ডাবল স্ক্রিপ্ট সাপোর্ট:** বাংলা (বিজয় ও অভ্র লেআউট অনুযায়ী) এবং ইংরেজি টাইপিং টেস্ট।
*   **রিয়েল-টাইম লাইভ ড্যাশবোর্ড:** টাইপ করার সময় লাইভ WPM, অ্যাকুরেসি, ভুল শব্দের সংখ্যা এবং মোট টাইপ করা অক্ষরের লাইভ ট্র্যাকিং।
*   **ইন্টারেক্টিভ কীবোর্ড ভিজ্যুয়ালাইজার:** স্ক্রিনে রিয়েল-টাইম কীবোর্ড যা পরবর্তী কোন কি প্রেস করতে হবে তা ইন্ডিকেট করে এবং ভুল কি প্রেস করলে তা লাল সংকেতে হাইলাইট করে।
*   **লিডারবোর্ড:** অনলাইন ক্লাউড লিডারবোর্ডের মাধ্যমে অন্যান্য ব্যবহারকারীদের সাথে আপনার স্কোর তুলনা ও র্যাঙ্কিং দেখার সুবিধা।
*   **বিস্তারিত পরিসংখ্যান (Analytics & Stats):** আগের সব পরীক্ষার ইতিহাস, ভুলের ধরন, গড় স্পিড এবং অগ্রগতির চার্ট গ্রাফিক্সের মাধ্যমে প্রদর্শন।
*   **অফলাইন মোড:** সম্পূর্ণ ইন্টারনেট সংযোগ ছাড়াই অফলাইনে আনলিমিটেড টাইপিং প্র্যাকটিস করার সুবিধা (অফলাইন স্টোরিজ)।

## ⚙️ ইনস্টলেশন গাইড (How to Install)

### 🪟 Windows
১. **ডাউনলোড:** উপরের বাটন বা [Releases](https://github.com/arman-khan-bd/bangla-typing-speed-meter/releases) থেকে `BnSpeedMeter.Setup.exe` ফাইলটি ডাউনলোড করুন।
২. **রান করুন:** ফাইলটিতে ডাবল ক্লিক করে ইন্সটল করা শুরু করুন।
৩. **SmartScreen সতর্কতা (যদি আসে):**
   * উইন্ডোজের সিকিউরিটি সার্টিফিকেটের কারণে উইন্ডোজ ডিফেন্ডার স্মার্টস্ক্রিন পপ-আপ দেখাতে পারে।
   * **More Info** বাটনে ক্লিক করুন।
   * **Run Anyway** বাটনে ক্লিক করে ইন্সটলেশন সম্পন্ন করুন।
৪. ইন্সটল সম্পন্ন হলে ডেস্কটপ শর্টকাট থেকে অ্যাপটি চালু করুন এবং আপনার ইউজারনেম দিয়ে টাইপিং শুরু করে দিন!

### 🍎 macOS
১. **ডাউনলোড:** আপনার ম্যাকের চিপ অনুযায়ী সঠিক DMG ফাইলটি ডাউনলোড করুন:
   * **Apple Silicon (M1/M2/M3):** `SpeedMeter-arm64.dmg`
   * **Intel Mac:** `SpeedMeter-x64.dmg`
২. **মাউন্ট করুন:** `.dmg` ফাইলটিতে ডাবল ক্লিক করুন।
৩. **ইন্সটল করুন:** `SpeedMeter.app` আইকনটি **Applications** ফোল্ডারে টেনে দিন (Drag & Drop)।
৪. **প্রথমবার চালু (Gatekeeper সতর্কতা):** `SpeedMeter.app`-এ **Right Click** → **Open** → পপ-আপে **Open** ক্লিক করুন।

> [!NOTE]
> macOS Gatekeeper সতর্কতা দেখালে ভয়ের কিছু নেই — এটি Apple-এর স্ট্যান্ডার্ড নিরাপত্তা প্রক্রিয়া।

### 🐧 Linux

**Debian / Ubuntu / Linux Mint (.deb)**
```bash
# ডাউনলোড করার পর টার্মিনালে রান করুন:
sudo dpkg -i SpeedMeter-amd64.deb
# অথবা ডাবল ক্লিক করে Software Center দিয়ে ইন্সটল করুন
```

**Fedora / RHEL / openSUSE (.rpm)**
```bash
# Fedora / RHEL:
sudo dnf install SpeedMeter-x86_64.rpm
# openSUSE:
sudo zypper install SpeedMeter-x86_64.rpm
```
ইন্সটল সম্পন্ন হলে অ্যাপ মেনু বা টার্মিনাল থেকে `speedmeter` কমান্ড দিয়ে চালু করুন।

> [!TIP]
> ARM64 Linux (যেমন Raspberry Pi) এর জন্য `SpeedMeter-arm64.deb` বা `SpeedMeter-aarch64.rpm` ব্যবহার করুন।

## 🛠️ ডেভেলপার গাইড (Developer Setup)

### ১. ক্লোন ও ইন্সটল
```bash
git clone https://github.com/arman-khan-bd/bangla-typing-speed-meter.git
cd bangla-typing-speed-meter
npm install
```

### ২. ডেভেলপমেন্ট মোড (React + Electron)
```bash
npm run electron:dev
```

### ৩. বিল্ড করুন

| কমান্ড | কোথায় চলে | আউটপুট |
|---|---|---|
| `npm run package:win` | ✅ Windows | `dist-electron/*.exe` |
| `npm run package:mac` | ✅ Mac only | `dist-electron/*.dmg` |
| `npm run package:linux` | ❌ Linux/WSL only | `dist-electron/*.AppImage` |
| `npm run package:linux-pkg` | ❌ Linux/WSL only | `dist-electron/*.deb`, `*.rpm` |

> [!IMPORTANT]
> Linux ও macOS বিল্ড Windows থেকে করা যায় না। এর পরিবর্তে **GitHub Actions** ব্যবহার করুন।

### ৪. GitHub Actions দিয়ে সব প্ল্যাটফর্মে Release করুন

প্রজেক্টে `.github/workflows/release.yml` ফাইলটি রয়েছে। এটি **তিনটি** আলাদা runner-এ (Windows, macOS, Ubuntu) স্বয়ংক্রিয়ভাবে বিল্ড করে এবং GitHub Release-এ আপলোড করে।

**Release করতে একটি git tag push করুন:**
```bash
git tag v1.0.0
git push origin v1.0.0
```

এটি automatically সব platform-এর বিল্ড তৈরি করে [GitHub Releases](https://github.com/arman-khan-bd/bangla-typing-speed-meter/releases) পেজে আপলোড করবে।
